without creating a competing exclusive DAC or editing microphone sharing.

fresh LINEOUT0 and encode the observed SPK OFF/ON baseline. The host verifies
these and all other routing values before invocation. The guardian restores both
controls independently of player success, cancellation or setup failure. This is
a diagnostic tool with host preflight, not a remotely exposed production worker.
No live microphone/speaker duplex or acoustic echo proof follows.
