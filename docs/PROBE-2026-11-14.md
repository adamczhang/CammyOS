Only existing software was used. No file, code, firmware, boot sector, mixer,
recording setting or motor command was written on the camera. Evidence is retained
locally under private/readonly-probe; credentials are excluded from this report.

## Consequence for the next release

The prepared [v0.2 TF runtime](archive/RELEASE-0.2.0.md) adds a fixed-allowlist diagnostics
endpoint so later investigations need less USB shell access. It preserves the
stock hardware stack and does not yet take over its devices. Raw probe logs,
configuration and any sensor evidence remain private and out of source control.
