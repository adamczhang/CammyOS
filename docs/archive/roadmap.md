# Roadmap

The goal of this project is to create a desktop companion robot similar to Reachy Mini Wireless from an M105 gimbal camera, with live video, session-enabled microphone audio, two-way speech, a screen face and agent-controlled gaze over home Wi-Fi.

The PC compatibility target is the official open-source Reachy Mini Control surface and SDK/daemon interface, with an explicit supported Cammy hardware subset and named extensions.
