# Native GUI face trial

Offline-only bounded immutable ParamFace surface, exact-source dual-hook
candidate and host/ARM/synthetic-native fixtures. Not installed or hardware
displayed. See [evidence, API map, lifecycle and next boundary](../../docs/NATIVE-FACE-TRIAL.md).

`make test-native-face` runs the focused verification profile. Builds and vendor
artifacts stay in ignored `build/native-face/` / `private/native-face/`.
No install, arm, firmware-write or native-restart command is provided.
